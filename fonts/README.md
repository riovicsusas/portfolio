# Portfolio fonts

Space Grotesk (500, 700) supplies headings; Manrope (400, 500, 600) supplies body text and controls. Latin WOFF2 files are sourced from Fontsource 5.3.0 packages for each family and served locally through `css/typography.css`. Font licenses are included beside the files. Existing monospace code typography and the Phosphor icon font remain separate.
