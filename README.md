## 🚀 Deployment (GitHub Pages)

This is a zero-build static site (HTML, CSS, JavaScript). You can host it on GitHub Pages in 2 steps:

1. In your GitHub repository, go to **Settings** → **Pages**.
2. Under **Build and deployment** > **Source**, choose either:
   - **Deploy from a branch**: Select `main` and root `/` (Instant deployment, no Actions needed).
   - **GitHub Actions**: Uses `.github/workflows/deploy.yml` for automated deployment.
